Support

Help happens in the open, on GitHub.

  1. Get help

    Open an issue on GitHub. Include your iPhone, iOS version, and how your server is reached.

  2. Security problems

    Please don’t post it publicly. Report it privately on GitHub.

  3. Is the server up?

    On the server machine, this should answer:

    curl -s http://127.0.0.1:8080/health

  4. An invite won’t open

    Invites work once and expire after three days, so ask for a new one. Or copy it and paste it on the app’s join screen.

  5. The app can’t find the server

    On home Wi-Fi the app finds it. Away from home, use the Tailscale address. See setup.

  6. Your data

    Export JSON or CSV in the app. Everything else is one SQLite file on your server. Developers can stream device logs.
