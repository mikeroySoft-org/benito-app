Set up Benito

Run a small server, then build the app with Xcode.

  1. Run the server

    On a Mac it starts at login and backs up nightly:

    git clone https://github.com/mikeroysoft-org/benito-app
cd benito-app && scripts/macos-service.sh install
curl -s http://127.0.0.1:8080/health

    On Linux or a NAS, use Docker.

  2. Reach it from phones

    • Tailscale, recommended: an HTTPS address anywhere.
    • Home Wi-Fi: a plain HTTP listener, for trusted networks only.
    • A VPS, behind Caddy or nginx with TLS.

  3. Install the app

    Not on the App Store yet, so build it with Xcode 16 or later:

    brew install xcodegen
cd apps/Benito && xcodegen generate
open Benito.xcodeproj

    First copy Local.xcconfig.example to Local.xcconfig and set your team.

  4. Invite your family

    Account, Sharing, Invite to Family. Send it by Messages, AirDrop, QR or SharePlay. Each works once, for three days.
